Jalur Backend — Vertonik Smart Farm

Satu request: klien → proxy → pipeline 8 langkah → router/guard → handler → cache/DB → JSON

4 lapis pengaman (urutan)

  • • requireAuth — JWT valid? → 401
  • • requireRole — semua / admin+demo → 403
  • • requireApiKey — X-API-KEY timing-safe → 403
  • • demoGuard + cek req.user.demo di handler → 403
  • • Rate limit login 10/menit/IP → 429

Cache & database

  • • latest-sensor 2 dtk · dashboard 5 dtk · thresholds 60 dtk
  • • pool pg max 50 koneksi, timeout 10 dtk
  • • save-sensor = 1 CTE (4 aksi dalam 1 round-trip)
  • • 8 index → grafik 100k baris ≈ 0,7 ms

Aturan respons

  • • JSON-only — satu-satunya non-JSON: 3 rute CSV
  • • Navigasi browser dibalas 204 kosong
  • • Error generik: { message } tanpa stack/SQL
  • • Kolom password & api_key tidak pernah ikut
