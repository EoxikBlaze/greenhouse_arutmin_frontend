Urutan Menyalakan Panel & Cek Awal Sebelum Operasi
LANGKAH 1

Cek Fisik & Cairan

Pastikan tandon terisi air, probe pH/EC terendam, tidak ada kabel terkelupas, dan selang pompa A, B, pH Up, pH Down tidak bocor/tertekuk.

LANGKAH 2

Bebaskan E-STOP

Pastikan tombol jamur merah E-STOP dalam kondisi tertarik/lepas (tidak tertekan). Cek pembagi 33k/10k & sekring daya 12V pompa.

LANGKAH 3

Nyalakan Raspberry Pi

Hidupkan daya Raspberry Pi dan router Wi-Fi / Modem terlebih dahulu. Tunggu ±1 menit sampai server API & MQTT siap menerima data.

LANGKAH 4

Nyalakan ESP32 Panel

Hidupkan panel kontrol ESP32. Tunggu layar LCD beralih menjadi PENAMPUNG CUKUP dan lampu pilot menyala HIJAU.

Fungsi Tombol RESET (GPIO 19):
• Tekan singkat: LCD menampilkan SSID Wi-Fi, IP ESP, IP Server Pi (SRV), & mode koneksi (MQTT/HTTP) selama 4 detik.
• Setelah darurat selesai: Lepas latch E-STOP lokal bila E-STOP fisik & server sudah normal.
• Ganti Wi-Fi/Modem via USB (115200 baud): ketik wifi NAMA|SANDI, server IP, scan, atau status (tanpa flash ulang).

4 Langkah Kalibrasi Probe & Pompa di Lapangan (Menu Website /kalibrasi)
1. Mode Pemeliharaan ON

Login sebagai Admin → buka Kalibrasi → klik Aktifkan pemeliharaan agar semua pompa otomatis dijeda aman.

2. Kalibrasi EC (2 Titik)

Bilas probe → celup larutan 1.413 µS/cm → tunggu stabil → Ambil titik 1.413. Bilas → celup 12.880 µS/cm → Ambil titik 12.880.

3. Kalibrasi pH (2 Titik)

Bilas probe → celup buffer pH 4,0 → tunggu stabil → Ambil titik pH 4,0. Bilas → celup buffer pH 7,0 → Ambil titik pH 7,0.

4. Kalibrasi Laju Pompa

Arahkan selang ke gelas ukur bersih → jalankan pompa 30/60 dtk → catat mL hasil ukur → klik Simpan laju. Matikan pemeliharaan setelah selesai.

⚠ PROTOKOL DARURAT & KESELAMATAN (K3 / E-STOP)

  • TEKAN TOMBOL MERAH E-STOP SEGERA jika terjadi kebocoran tandon/selang, pompa terus menyala tidak wajar, bau komponen panas, atau korsleting listrik.
  • JANGAN MELEPAS E-STOP SEBELUM AMAN: Periksa sumber masalah, keringkan cipratan air di sekitar panel, baru putar/tarik tombol E-STOP, reset dari Admin (jika dipicu server), lalu tekan tombol RESET (GPIO 19).
  • UJI AWAL SELALU PAKAI AIR BERSIH: Jangan pernah menyuntik pupuk pekat langsung ke tandon saat uji pompa atau ganti selang baru.
  • DAYA POMPA 12V TERPISAH: Jika pompa tetap berputar saat daya ESP32 dicabut, HENTIKAN PENGGUNAAN dan perbaiki wiring relay segera.
Batas Pengaman Tetap Firmware (gabungan-0.6)
• Nutrisi AB: Maks 214 mL/suntik • Maks 450 mL/jam • Relay maks 70 dtk
• pH Up/Down: Maks 10 mL/suntik • Maks 30 mL/jam • Relay maks 12 dtk
• Isi Air: Maks 600 dtk • Stop otomatis saat pelampung atas penuh
• Fail-Safe Sinyal: Wi-Fi / Pi putus → seluruh pompa mati ≤ 30 detik
• Anti Belum Kalibrasi: Laju 0 mL/dtk otomatis ditolak
