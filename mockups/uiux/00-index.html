Cara pakai dokumen ini

  • Setiap file = 1 halaman: header berisi route + role, wireframe zona, lalu catatan state.
  • Grayscale + label kotak = struktur fungsi saja; styling visual (warna/font/brand) dikerjakan terpisah.
  • Chrome global (sidebar/topbar) identik di semua halaman — lihat file 18.
  • Untuk PenDev/Figma: 1 file = 1 frame.
