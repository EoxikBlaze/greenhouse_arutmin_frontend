Bibit SIAP / BELUM SIAP

SIAP

Isi berhasil + gagal = jumlah semai, pilih meja tujuan → tahap pertumbuhan. Berhasil 0 → siklus selesai (gagal semai).

BELUM SIAP / tidak dijawab

Kembali ke semai. Bibit tidak pernah dianggap siap tanpa jawaban. Muncul notifikasi "Konfirmasi terlewat".

Yang dilakukan operator sekarang

  • Catat tahap di Kebun Saya: isi jumlah berhasil.
  • Beri nutrisi & koreksi pH manual (SOP-01 SOP 5), ukur dengan alat pembanding.
  • Catat di log nutrisi manual.

Angka naik/turun tidak wajar

  • Angka mustahil → ditolak server.
  • 3× mustahil berturut → sensor dianggap rusak, penampung dikunci.
  • Ukur ulang dengan alat pembanding, lapor admin.

Dilarang

  • Mencoba menjalankan pompa dosing dari web, HP, atau Serial.
  • Mengubah pengaturan keamanan tanpa keputusan pemilik.
Dosing otomatis baru boleh setelah kalibrasi, uji pengaman, uji 24 jam, validasi parameter & keputusan tertulis pemilik.
