Cara Menggunakan
Website GARAP

Pantau greenhouse dari browser dalam 6 langkah.

6langkah
harian
1

Buka alamat website

Sambung ke Wi-Fi greenhouse. Ketik alamat server di browser, mis. garap.local.

2

Masuk dengan akun Anda

Isi nama pengguna dan kata sandi, tekan Masuk ke Dashboard. Jangan pinjamkan akun.

3

Cek Dashboard

Pastikan label Alat tersambung. Pita kuning = angka lama, bukan kondisi sekarang.

4

Lihat Sensor

Pilih rentang 6 Jam / 24 Jam / 7 Hari. Tekan Unduh Laporan untuk berkas Excel.

5

Tanggapi Peringatan

Buka Peringatan. Kerjakan tindakan sesuai SOP. Admin menekan Tandai selesai.

6

Catat tanam

Kebun Saya → Mulai Semai Baru. Saat tahap selesai, isi jumlah berhasil.
