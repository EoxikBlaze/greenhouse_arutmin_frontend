Mengenal GARAP – Smart Hidroponik

Satu sistem untuk memantau air nutrisi, mencatat siklus tanam, dan mengamankan pompa di greenhouse.

OperatorPengelola greenhouseMitra
Apa itu GARAP?

Platform hidroponik pintar untuk greenhouse

GARAP = Green Autonomous Responsive Agriculture Platform

Sistem pemantauan, pencatatan budidaya, asisten agronomi lokal, dan pengendalian perangkat hidroponik berbasis IoT. Nama produk di layar: Vertonik Smart Farm.

Tujuan sistem

  • Kondisi air nutrisi terpantau setiap saat.
  • Siklus tanam 4 tahap tercatat rapi.
  • Pompa dilindungi pengaman berlapis.
  • Keputusan operator didukung data, bukan tebakan.
Gambaran umum

Dari tandon ke layar Anda

Data sensor naik ke server lokal, lalu tampil di website dan aplikasi. Perintah dari pengelola turun melalui jalur yang sama.

Perangkat IoT

ESP32 di panel membaca sensor tiap 5 detik dan mengendalikan pompa.

Server lokal

Raspberry Pi menyimpan data, menjalankan backend, MQTT, dan Asisten AI.

Website & aplikasi mobile

Operator memantau, mencatat tanam, dan menerima peringatan.

Komponen utama

Empat bagian yang bekerja bersama

Sensor

pH, EC/TDS, suhu air, suhu & kelembapan udara, pelampung tandon.

Panel ESP32

Firmware gabungan-0.6, LCD 20×4, lampu pilot, tombol E-STOP & RESET.

Raspberry Pi

Backend Node.js, PostgreSQL, broker Mosquitto, Nginx, Ollama.

Website & Flutter

Website React di browser dan aplikasi Android/iOS GARAP.

Manfaat

Yang Anda dapatkan

Pantau tanpa menebak

Angka sensor terbaru, batas aman, dan grafik riwayat di satu layar.

Peringatan dini

Kondisi di luar ambang dan gangguan alat muncul di menu Peringatan.

Aman berlapis

E-STOP fisik, pelampung, batas mL, dan detak server 30 detik di firmware.
