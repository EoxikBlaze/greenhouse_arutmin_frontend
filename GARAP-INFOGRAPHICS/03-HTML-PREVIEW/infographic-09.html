Troubleshooting GARAP

Gejala → kemungkinan penyebab → langkah pemeriksaan → tindakan. Operator dan teknisi punya bagian masing-masing.

OperatorTeknisi
Operator

Tindakan operator

Pemeriksaan visual, website, tombol RESET singkat, E-STOP, dan melapor.

Teknisi

Tindakan teknisi

Membuka panel, kabel/sekring, Serial Monitor ESP32, perintah di Raspberry Pi, kalibrasi.

Matriks gangguan

Tujuh gangguan yang paling mungkin

GejalaKemungkinan penyebabLangkah pemeriksaanTindakan
Sensor tidak terbacaProbe lepas/kotor, kabel sensor putus.LCD tampil pH --.-- / EC ----; nilai di Dashboard kosong.OperatorCatat waktu, lapor teknisi.
TeknisiPeriksa probe & kabel; cek status di Serial Monitor (115200).
Data tidak masuk websiteHP beda jaringan, IP Pi berubah, layanan web/API berhenti.Pastikan Wi-Fi sama dengan Pi. Tekan RESET singkat → baca IP server di LCD 4 detik.OperatorBuka http://vertonik.local atau IP dari LCD.
TeknisiPeriksa layanan nginx & vertonik-api di Pi.
MQTT terputusPort 1883 diblokir router, *client isolation* aktif.LCD HTTP SENSOR ONLY atau TUNGGU SERVER...; lampu merah + hijau.OperatorPompa terkunci aman. Lapor.
TeknisiMatikan AP/client isolation; cek sudo ufw status / siapkan-modem.sh.
ESP32 tidak terkoneksiWi-Fi 5 GHz / sandi berubah / sinyal lemah.LCD WIFI MATI. Dashboard: alat terputus.OperatorPastikan router menyala; lapor.
TeknisiSerial: scan, lalu wifi NAMA|SANDI; cari untuk IP Pi.
Pompa tidak meresponsE-STOP aktif, detak server hilang > 30 dtk, laju belum_dikalibrasi, mode pemeliharaan.Lihat lampu merah saja / LCD E-STOP AKTIF!. Cek Peringatan. *Eksekusi dosing memang diblokir.*OperatorJangan memaksa. Lapor penyebab yang terlihat.
TeknisiCari sebab E-STOP; kalibrasi laju pompa di halaman Kalibrasi.
Pembacaan tidak normalProbe perlu kalibrasi, probe di luar air, gelembung udara.Bandingkan dengan alat ukur manual; nilai di luar rentang wajar (pH 3–9, TDS 50–2.500 ppm, suhu air 5–45 °C).OperatorPeriksa fisik tandon; jangan menambah nutrisi/pH manual.
TeknisiKalibrasi 2 titik EC & pH.
Gangguan dayaListrik padam, adaptor rusak, korsleting.Panel/LCD mati, Dashboard data usang. Ada bau hangus atau percikan?OperatorBau/percikan: tekan E-STOP, menjauh, panggil teknisi.
TeknisiMatikan sumber daya, periksa sekring & catu 12 V.

Berhenti dan panggil teknisi bila

  • Ada air di dekat panel atau kabel.
  • Tercium bau hangus, terlihat asap/percikan.
  • Lampu merah saja tidak padam setelah penyebab dibereskan.
  • Gangguan berulang setelah RESET.
